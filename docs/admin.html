League administration

Run the game.

Fixtures, live scoring, final results and player statistics are managed in the official TeamLinkt league. Changes made there flow into this site’s schedule, scores, standings and stats widgets.

Authorised league admins only. Sign in to TeamLinkt with your league admin account. This page does not keep a second scorebook: the public widgets read the official TeamLinkt record.
01 / FIXTURES

Create or reschedule a game

Use TeamLinkt’s schedule tools to add or edit fixtures, dates, start times, divisions and teams. Save there to update the public schedule.

Open TeamLinkt admin ↗
02 / LIVE GAME

Start live scoring

In the TeamLinkt app, open the scheduled event and choose “Game is live now”. Use Update to adjust the live score or clock.

Open TeamLinkt ↗
03 / FINAL SCORE

Submit the game result

In the league admin Schedule → Scores view, choose the event’s Actions → Set Score, enter both scores, mark the game complete and save.

Open score administration ↗
04 / PLAYER STATS

Enter official player stats

After saving the score and completing the game, choose Actions → Stats for the event, enter the player statistics for both teams and save. The public Stats widget uses this same TeamLinkt data.

View official stats ↗
